# Step 2 update

Upload the `src` folder from this update into the root of the existing GitHub
repository. Choose **Replace** when Codespaces asks about existing files.

Then run:

```bash
npm run dev
```

After reviewing the homepage, stop the server with the Control + C keyboard
shortcut and commit the update one command at a time:

```bash
git add .
git commit -m "Build portfolio hero and selected work"
git push
```

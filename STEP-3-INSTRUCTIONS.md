# Step 3 update

This is a complete project package containing Steps 1–3.

Copy everything inside this folder into the root of the existing Codespaces
repository and choose **Replace/Overwrite all**.

Run `npm run dev`, then open the first project card to review the new case study.

After approval, stop the server using the Control + C keyboard shortcut and run
these commands one at a time:

```bash
git add .
git commit -m "Add medical claim case study"
git push
```
